## Diagnosis
Root cause: CouponScanner remembers the camera grant in SharedPreferences (`camera_granted`, set once on first grant) and the Scan button trusts that flag without asking the system. `hasCameraAccess` returns the stored boolean (CouponScanner.kt:33-34), and the click handler calls `open` directly when it is true (CouponScanner.kt:76-77), skipping the permission request. After the user revokes CAMERA in Settings the flag stays true, so `CameraManager.openCamera` is called without permission and throws SecurityException (CouponScanner.kt:44). Nothing clears the flag when the permission disappears.
Fix approach: Drop the SharedPreferences grant cache. Check the live permission at each tap with ContextCompat.checkSelfPermission(context, CAMERA) and only call open() when it returns GRANTED; otherwise launch the RequestPermission contract again. Put the permission check behind a small injectable function so the decision can be unit tested. Optionally wrap openCamera in try/catch SecurityException and surface an error status as a fallback.
Evidence: app/src/main/java/com/shubhasai/monkeymart/ui/CouponScanner.kt:31-34 - the only camera-access state is a SharedPreferences boolean `camera_granted`, read by hasCameraAccess; app/src/main/java/com/shubhasai/monkeymart/ui/CouponScanner.kt:36-38 - rememberCameraGranted writes true once and nothing ever writes false or re-checks the system permission; app/src/main/java/com/shubhasai/monkeymart/ui/CouponScanner.kt:64-67 - the permission result callback sets the cached flag and opens the camera; app/src/main/java/com/shubhasai/monkeymart/ui/CouponScanner.kt:76-77 - the Scan button opens the camera whenever the cached flag is true, with no live permission check; app/src/main/java/com/shubhasai/monkeymart/ui/CouponScanner.kt:41-44 - open() calls cameras.openCamera with @SuppressLint("MissingPermission"), so a revoked permission throws SecurityException here; app/src/main/java/com/shubhasai/monkeymart/ui/CheckoutScreen.kt:74 - the checkout form hosts ScanCouponButton() with no permission handling of its own
